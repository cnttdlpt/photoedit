# Product
<!-- impeccable:product-schema 1 -->
## Platform
adaptive
## Users
Vietnamese-speaking photo editors. User confirmed quick edits first, with advanced tools retained.
## Product Purpose
IRO imports a photo, applies film recipes and adjustments, optionally adds frames, and exports the result.
## Operating Context
Web browser, native SwiftUI iOS and Java Android. Primary workflow: import → film recipe → adjust → export. The user requires the full recipe catalog accessible directly, reliable Back/Cancel, and import opening the editor.
## Capabilities and Constraints
Preserve existing color engines, source-based rendering, undo/redo, LUT, LightCraft, frames, account and cloud capabilities. Latest GitHub main c292816 includes guest navigation fixes; ios/android refs are 0e89315. Morphicons is requested for the web; native platform controls remain native. Native bindings for SwiftUI/Java are not supplied by Morphicons.
## Brand Commitments
IRO name and Vietnamese interface. User requests taste-skill and impeccable for the redesign.
## Evidence on Hand
Source, recipes, sample assets, web tests, Android checks, iOS XCTest and portable core checks. Do not invent recipe counts or claims.
## Product Principles
- Image and next action lead.
- Quick workflow without removing advanced capability.
- Back, cancellation and undo remain available.
- Shared vocabulary with native OS interaction.
